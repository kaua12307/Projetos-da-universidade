# Display 7 Segmentos
Este projeto consiste na implementação de um display de 7 segmentos no software Logisim Evolution, utilizando técnicas de simplificação lógica por meio de Mapas de Karnaugh.

O objetivo do projeto é representar números decimais em um display de 7 segmentos a partir de entradas binárias, realizando a construção e otimização das funções booleanas responsáveis pelo acionamento de cada segmento do display.

Durante o desenvolvimento, foram elaboradas as tabelas verdade, os mapas de Karnaugh correspondentes a cada segmento e, posteriormente, a implementação do circuito lógico no ambiente do Logisim.

O projeto tem caráter educacional, sendo voltado ao estudo de:

Álgebra Booleana

Simplificação de funções lógicas

Circuitos combinacionais

Displays de 7 segmentos

Projeto e simulação digital.
